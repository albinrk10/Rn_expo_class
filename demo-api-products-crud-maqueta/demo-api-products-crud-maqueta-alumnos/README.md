# Maqueta alumnos — CRUD API Products con Axios

Maqueta para completar en clase.

La UI ya está lista. Debes completar el archivo:

```text
services/productsApi.ts
```

## Antes de ejecutar

Entra a:

```text
https://crudcrud.com
```

Copia tu endpoint y reemplaza:

```ts
const CRUDCRUD_BASE_URL = 'https://crudcrud.com/api/REEMPLAZA_TU_TOKEN';
```

## Ejecutar

```bash
npm install
npm start
```

## Qué completar

1. `GET /products`
2. `POST /products`
3. `PUT /products/{id}`
4. `DELETE /products/{id}`
5. Revisar logs en consola.

## Logs esperados

```text
[API REQUEST] GET ...
[API RESPONSE] 200 ...
[API DATA] ...
```
